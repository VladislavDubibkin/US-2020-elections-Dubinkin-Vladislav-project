Один из моих нескольких проектов, сделанных в Jupiter Notebook с использование библиотек NumPy, Pandas, SeaBorn, Matplotlib и Plotly. Тему и датасет я находил на платформе Kaggle. В рамках этого проекта я самостоятельно изучал, как географический, культурный и даже половой фактор влиял на электоральный климат одной из крупных стран мира, а также попрактиковал свои навыки в чистке и трансформации данных.
