# Анализ датасета из Kaggle
Один из моих проектов, выполненных в Jupyter Notebook с использованием библиотек NumPy, Pandas, Seaborn, Matplotlib и Plotly. Сам датасет был взят на платформе Kaggle. В рамках этого проекта я самостоятельно изучал влияние географических, культурных и других факторов на электоральный климат одной из крупных стран мира, а также попрактиковался в очистке и преобразовании данных. (Весь проект был выполнен на английском языке из-за специфики датасета и программы моего обучения).
